# 🧠 Landing Page - AlphaMec Clínica

Landing page moderna e responsiva para clínicas de saúde/psicologia, desenvolvida com HTML5, CSS3 e JavaScript puro. O projeto inclui todas as seções essenciais, integração completa com WhatsApp (botão flutuante, botões estratégicos e formulário com redirecionamento automático), mapa interativo do Google Maps e navegação suave.

## 📋 Funcionalidades

- ✅ **6 Seções completas**: Hero, Serviços, Equipe, Horários, Localização e Contato
- ✅ **Navbar fixa** com links âncora para navegação suave
- ✅ **Botão flutuante do WhatsApp** (fixo na tela)
- ✅ **Botões WhatsApp** no Hero e na Navbar
- ✅ **Formulário de contato** que redireciona automaticamente para o WhatsApp com mensagem personalizada
- ✅ **Google Maps incorporado** (responsivo)
- ✅ **Tabela de horários** de atendimento (segunda a domingo)
- ✅ **Cards responsivos** para serviços e equipe
- ✅ **Design 100% responsivo** (mobile, tablet e desktop)
- ✅ **Placeholder para logo** (espaço reservado para imagem PNG)

## 🛠️ Tecnologias Utilizadas

- HTML5
- CSS3 (Flexbox, Grid, Media Queries)
- JavaScript (Vanilla)
- Font Awesome 6 (CDN)
- Google Maps Embed API
